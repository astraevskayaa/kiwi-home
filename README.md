# Киви дома v2.1 🐾

Обновление: прозрачные стикеры Киви из присланной фотографии, обновлённая главная карточка, правило про окна, ужин с паштетом по средам.

## Публикация

1. Распакуйте ZIP **локально**. Не загружайте ZIP как один файл в GitHub.
2. В корне репозитория `kiwi-home` замените `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest` и папки `photos/`, `icons/`.
3. Убедитесь, что `index.html` лежит в **корне**, а не в папке `kiwi-home-v2-1/`.
4. Сделайте Commit, дождитесь GitHub Pages.
5. При старом отображении откройте сайт в приватной вкладке Safari или удалите старую иконку с домашнего экрана и установите снова.

Ссылка на общий список Apple «Напоминания» задаётся в `app.js`: `REMINDERS_URL`.

GitHub Pages публичный: не размещайте пароли, коды доступа и личные номера без необходимости.
