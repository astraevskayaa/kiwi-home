# Киви дома 🐾

Статическое PWA для GitHub Pages. Без сервера, сборки и базы данных.

## Публикация
1. Создайте новый репозиторий GitHub, например `kiwi-home`.
2. Загрузите содержимое этой папки **в корень** репозитория (не папку целиком).
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Откройте `https://ВАШ-ЛОГИН.github.io/kiwi-home/`.
5. На iPhone откройте сайт в Safari → «Поделиться» → «На экран Домой».

## Чек-лист Apple
Создайте общий список в «Напоминаниях» и пригласите друзей. При наличии подходящей ссылки впишите её в `app.js` в `REMINDERS_URL`. Ссылка приглашения может не служить постоянной прямой ссылкой на список: проверьте на телефонах друзей. Галочки в самом PWA не синхронизируются с Apple.

## Изменение инструкций
Тексты находятся в `app.js`. После изменения файлов на GitHub сайт обновится. Если приложение показывает старую версию, откройте сайт с интернетом и перезапустите приложение.

## Важно
GitHub Pages — публичный хостинг. Не размещайте здесь пароли, коды доступа, номера телефонов и другую конфиденциальную информацию. Указанные даты относятся к ноябрю 2026 года. Время кормления — местное время пользователя. При необходимости обновите тексты и расписание.
