# Киви дома 🐾 — версия 2.0

Обновление с настоящими фотографиями Киви, компактным расписанием и карточками с раскрывающимися подробностями.

## Обновление GitHub Pages
1. Распакуйте архив.
2. Загрузите **содержимое** папки `kiwi-home-v2` в корень существующего репозитория `kiwi-home`, заменив старые файлы. Не забудьте папку `photos`.
3. Подождите публикации GitHub Pages и обновите приложение на iPhone (если видна старая версия, закройте и откройте приложение заново).
4. Ссылка на общий список Apple «Напоминания» по-прежнему задаётся в `app.js` через `REMINDERS_URL`.

Фото и инструкции будут публично доступны любому, кто знает адрес сайта. Не добавляйте пароли или личные данные.
